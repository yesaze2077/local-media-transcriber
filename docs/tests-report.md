# v0.1.0 测试报告（2026-11-13）

本轮完成 75 项自动化测试及 19 项真实本地集成场景的执行检查。指定双人的合成声线标签一致率为 100%；自动人数估计在同一双声线样本上产生 4 簇，人数准确性检查未通过，不能将自动簇数视为真实人数。

## 环境与证据

- macOS 26.5.1、Apple Silicon arm64、32GB RAM；Python 3.11.14。
- FunASR 1.4.26、PyTorch/Torchaudio 2.8.0、NumPy 2.4.6；CPU、4线程。
- 五个模型均真实加载/推理：Paraformer-zh、FSMN-VAD、CT-Punc、CAM++、SenseVoiceSmall。权重以固定 HF revision 的 LFS SHA256 验证，传输来自官方 ModelScope 镜像；配置来自固定 HF revision。
- [机器可读集成结果](validation-results.json)、[许可审计](dependency-licenses.json)、[模型许可证据](model-license-evidence.json)。公开报告去掉本机私人路径，不包含录音、逐字稿和声纹向量。
- 测试语料由原始测试文案经本机 `say` 合成；语音是实际音频，ASR/声纹推理使用真实模型。不是人工真实访谈，不能作为真实世界准确率基准。

## 软件测试与构建

`pytest -q`：75 passed。模型下载器独立审查发现的无效断点类型、残留超长文件问题已修复，并通过9项下载相关回归。测试也覆盖坏哈希不激活、损坏块重下载、失败重试、活锁与失效锁、输入推理期间变化、损坏输出另建attempt、字典/人名替换、说话人引用和日志脱敏。

`ruff check`、Skill `quick_validate`、Shell语法检查、源码/轮子构建均通过。构建产物包含模型注册表和JSON Schema。框架测试中的stub只用于错误/重试等边界，不作为ASR成功证据。

完整ASR必须使用仓库uv frozen安装：已排除评估许可的kaldiio，原始MIT适配层明确拒绝Kaldi archive操作，不实现或模拟这些操作。普通音视频推理路径已通过上述真实模型验证。详见[许可说明](../THIRD_PARTY_NOTICES.md)。

## 仅实现或未验证

- 日语、韩语、粤语模型选择路径已实现，尚未做真实语言样本验证。
- Windows 11、Linux、Intel Mac的物理设备推理未验证；CI只检查通用软件路径，不代表ASR设备兼容性。
- 真实会议、访谈、远场、方言、小时级长录音、背景音乐和强噪声语音准确率未验证。
- 自动人数会过估；建议已知人数时显式 `--speakers N` 并复核 `speaker_uncertain`。
- SenseVoice使用VAD区间时间，没有伪造字级或句级精细对齐。短时换人、混合标签句子仍可能归错。
- 全局声纹聚类限制5000个短窗，超限会明确拒绝，需拆分或禁用聚类。

## 尚未支持

重叠语音源分离、声纹直接识别真实身份、内置语义翻译/摘要、外部LLM调用、GUI、在线平台媒体抓取、Kaldi `.ark/.scp`。原始逐字稿仍可能漏字、替换口语或专业术语，需要人工校对。

## 复现

```bash
bash install.sh
.venv/bin/transcribe models download cam++
.venv/bin/transcribe models download sensevoice-small
make test
make lint
make build
# macOS，本机合成语料；选择一个全新的私有输出目录
.venv/bin/python examples/validate_local.py --work-dir /private/tmp/lmt-validation-new
```

原始本地验证结果保存在运行者指定的私有目录；不要将这些逐字稿、声纹向量或私人素材放入公开仓库。
