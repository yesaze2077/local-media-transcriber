# v0.1.2 极短第三位发言修复验证（2026-11-13）

原来被归入两人之一的1.5秒第三位发言，现在输出3簇。13个必需合成语音场景全部通过“人数准确匹配＋每种声线标签一致率≥0.8”门槛，实际每种声线一致率均为1.0；既有单人、双人和三人场景保持通过。此结果只适用于列出的合成样本，不代表真实访谈的通用准确率。

## 根因与改动

v0.1.1的细尺度少数声线复核要求至少3窗和3秒连续支持。1.5秒第三位留下两个主要CAM++窗口，声纹已区别于已有群组，但细图未提出可提升的组，且不满足原支持门槛。相同私有检查点重放三次均得到2簇。

本版保留原有图划分和3秒路径，在它们之后增加严格的两窗候选复核。候选必须同声道、同父簇，起点不同且确有时间重叠；两个窗口各至少1秒，时间并集至少1.5秒。每窗至少60%的20ms音频帧达到相对能量门槛，且各自的ASR词元时间在共同重叠区间覆盖至少200ms。两窗余弦距离≤0.25、均值中心距所有已有簇≥0.25，提升后原父簇至少保留3窗。重叠窗口不会被当成两份独立发言时长累计。

原失败样本的两个主要窗口共享区间有750ms词元支持，活动帧占比分别约0.81和0.69，满足新复核；原双人转场反例的低活动或不一致声纹没有被提升。能量只是非静音支持，ASR时间也可能出错，均不是真实身份或语音真值。

缺少音频活动或对齐时间时不启用两窗提升。当前SenseVoice没有细粒度词元时间，因此不宣称此改动解决其极短发言漏分。指定人数模式继续原有受约束聚类路径。新证据仅随声纹保存在私有分块检查点中，不进入公开逐字稿导出。版本号参与任务指纹；升级后重跑使用新任务，旧成果保留。

## 重现与边界

已安装模型后，在私有目录执行（目录应为空；尖括号为占位符）：

```bash
LMT_STATE_DIR="<新的私有state目录>" .venv/bin/python examples/validate_speaker_count.py \
  --work-dir "<新的私有验证目录>"
LMT_STATE_DIR="<另一个私有state目录>" .venv/bin/python examples/validate_local.py \
  --work-dir "<新的私有完整管线目录>"
.venv/bin/python -m pytest -q
.venv/bin/ruff check src tests examples
```

人数脚本任一必需场景数量不匹配、任一声线一致率<0.8或推理异常均失败，不降级为诊断项。想精确重用已有原样本，可另外传`--original-fixtures`指向私有原始验证目录。

只剩一个可靠窗口、没有对齐时间、极低音量或更短发言仍可能漏分；既有声线剧烈变化也可能产生误分。交叠发言、远场、方言、真实自然人访谈与小时级录音尚无准确率基准。阈值不是已校准概率，已知人数时可用`--speakers N`并核对`speaker_uncertain`，不能据此确认真实身份。
