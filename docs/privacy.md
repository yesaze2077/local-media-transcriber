# Privacy and storage

Local Media Transcriber sends no audio, video or transcript to a transcription API. Normal `run` and `batch` operations require downloaded local checkpoints and operate offline. Download/setup commands contact Python/package hosts, Hugging Face for pinned model metadata/configuration, and by default the publisher's official ModelScope mirror for large weight files (`LMT_WEIGHT_SOURCE=hf` selects direct Hugging Face weights); these hosts see normal connection metadata. A checkpoint can contain executable code, so use the registered publisher sources and recorded revisions.

Source files remain untouched. FFmpeg writes program-owned temporary PCM files; they are removed after processing. Persistent resumable state contains the raw transcript and, when CAM++ is enabled, speaker embedding vectors in chunk checkpoints. These vectors and text are sensitive local data, even though they are not uploaded. Protect the private state directory like the source recording. Removing temporary WAV files does not remove transcripts, checkpoints or filesystem backups. Logs are operational and must not include transcript bodies or full private source paths.

By default models are under the OS user cache directory for `local-media-transcriber`; jobs/checkpoints are under the OS user data directory for that app. On macOS these are `~/Library/Caches/local-media-transcriber/` and `~/Library/Application Support/local-media-transcriber/`. `LMT_CACHE_DIR` and `LMT_STATE_DIR` can point to private storage. Outputs use the directory selected by the user. The Python virtual environment is `.venv/` in the checkout.

This version automatically cleans only its own temporary media via bounded temporary directories; it does not offer an automatic state-deletion command. Users may deliberately remove app-owned cache/state after checking the paths and retention needs; this removes resume data and may require model redownload. There is no automatic deletion of original media or completed results. Do not place recordings, dictionaries containing personal data, task state, outputs or model weights in a public repository. The CLI does not know whether a source recording was lawfully collected; obtain appropriate recording and data-use authorization for your use case.
